One line roasting a smart fridge, written for the [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

## The entry

> I updated my firmware last night. I now have 14 new features and none of them is making ice.

92 characters, one line. The joke only works because it is a *smart* fridge: it can update its firmware, gain features, and still fail at the one job a fridge has always had.

## How it works

`main.py` (Python standard library only) validates the line against the bounty gate — 1–200 UTF-8 characters, a single line, not only whitespace — then writes it to `/output/entry.txt`.

```bash
python3 main.py
cat /output/entry.txt
```
